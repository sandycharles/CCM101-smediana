# Laboratory Activity 1 – Mission 1: Welcome to the Cloud

## Mission Overview
This activity involved onboarding as a Junior Cloud Infrastructure Engineer
Trainee at CloudNova Technologies, learning to work inside a Linux
environment, documenting work professionally, and maintaining a
version-controlled portfolio on GitHub.

## Objectives
- Access a cloud-based Linux environment using KillerCoda
- Explore and navigate the Linux operating system
- Gather basic system information
- Organize files and directories using Linux commands
- Create and maintain a professional GitHub repository
- Document technical work using Markdown

## Activities Performed
- Launched an Ubuntu Linux Playground on KillerCoda
- Created a new user (smediana) with sudo privileges and logged in
- Verified username, working directory, and hostname
- Gathered system information (distro, kernel, CPU, memory, disk space)
- Built a folder structure (Documents, Notes, Reports, Screenshots)
- Created and viewed markdown files (about-me.md, system-information.md)
- Created a public GitHub repository and structured it as a Cloud
  Computing Portfolio
- Documented this laboratory activity using Markdown

## Linux Commands Used
`whoami`, `pwd`, `hostname`, `cat /etc/os-release`, `uname -r`, `lscpu`,
`free -h`, `df -h`, `mkdir`, `nano`, `cat`, `ls`, `git clone`, `git add`,
`git commit`, `git push`

## Skills Learned
- Basic Linux navigation and system inspection
- User account creation and privilege management (sudo)
- File and directory organization
- Markdown documentation practices
- Git and GitHub repository structuring and version control
