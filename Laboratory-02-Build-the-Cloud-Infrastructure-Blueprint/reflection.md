Mission Reflection

1. Which cloud infrastructure component do you think is the most important? Why?

I think networking is one of the most important cloud infrastructure components because it allows compute, storage, applications, and users to communicate with each other. Even if a cloud server has enough CPU, memory, and storage, it would not be very useful if users and other services could not access it. During the laboratory, I saw how network interfaces and IP addresses connect different resources. However, compute, storage, and networking must work together for a complete and functional cloud infrastructure.

2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable, secure, lightweight, and flexible operating system for servers and virtual machines. It is widely supported by major cloud providers such as AWS, Microsoft Azure, and Google Cloud. Linux also provides powerful command-line tools that make it easier to monitor resources, configure systems, automate tasks, and troubleshoot problems. During this laboratory, I used commands such as `lscpu`, `free -h`, `df -h`, and `ip a` to examine the Linux environment and understand how its resources relate to cloud infrastructure.

3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the resources, configurations, decisions, and relationships within an infrastructure. Good documentation helps engineers understand the system before making changes and makes troubleshooting easier when problems occur. It also improves teamwork because other people can understand the project without having to investigate everything themselves. In this laboratory, documenting the infrastructure findings helped organize the information and connect the Linux environment to real cloud computing concepts.

4. What new skills did you learn during this laboratory activity?

I learned how to examine a Linux server and identify its CPU, memory, storage, network interfaces, and operating system using command-line tools. I also learned how these resources correspond to cloud infrastructure services such as compute, storage, and networking. Another skill I developed was comparing AWS, Microsoft Azure, and Google Cloud services. I also improved my Git and GitHub skills by creating files, committing changes, configuring Git identity, and pushing the completed work to a repository.

5. How has your GitHub portfolio improved after completing this mission?

My GitHub portfolio has improved because it now contains a more complete cloud computing laboratory project with technical documentation, cloud infrastructure research, cloud provider comparisons, and a mission reflection. The project demonstrates that I can investigate a Linux environment, understand basic cloud infrastructure concepts, organize technical information, and document my work using Markdown and Git. This makes my portfolio more practical because it shows both my knowledge and my ability to apply it in a hands-on environment.
