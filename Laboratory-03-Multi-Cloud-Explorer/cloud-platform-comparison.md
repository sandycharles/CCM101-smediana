# Cloud Platform Comparison

## Checkpoint 3 – Core Comparison Table

| Category | AWS | Microsoft Azure | Google Cloud Platform |
|---|---|---|---|
| Launch Year | 2006 | 2010 | 2008 |
| Compute Service | EC2 (Elastic Compute Cloud) | Azure Virtual Machines | Compute Engine |
| Storage Service | S3 (Simple Storage Service) | Blob Storage | Cloud Storage |
| Networking Service | VPC (Virtual Private Cloud) | Azure Virtual Network (VNet) | Virtual Private Cloud (VPC) |
| Identity Service | IAM (Identity and Access Management) | Microsoft Entra ID (formerly Azure AD) | Cloud IAM |
| Primary Strength | Broadest service catalog, mature ecosystem, and strong market presence | Deep integration with Microsoft enterprise tools such as Microsoft 365, Windows Server, and Entra ID | Strong data analytics, artificial intelligence, machine learning, and Kubernetes capabilities |
| Ideal Organizations | Startups to large enterprises needing flexibility and a wide variety of cloud services | Enterprises already invested in the Microsoft technology ecosystem | Data-driven companies, AI/ML teams, and cloud-native organizations |

### Q1: Which cloud provider offers the broadest range of services?

**AWS generally offers the broadest range of cloud services among the three major providers.** It has a large and mature service catalog covering computing, storage, databases, networking, security, analytics, machine learning, and many specialized workloads. AWS also has one of the longest track records in the public cloud market, having launched its major cloud services in 2006.

### Q2: Which provider best integrates with Microsoft technologies?

**Microsoft Azure provides the strongest integration with Microsoft technologies.** Because Azure is developed and operated by Microsoft, it integrates closely with Microsoft Entra ID, Microsoft 365, Windows Server, SQL Server, and .NET development tools. This makes Azure a particularly suitable choice for organizations that already depend heavily on Microsoft's enterprise software.

### Q3: Which provider is strongest in Artificial Intelligence and Kubernetes?

**Google Cloud Platform (GCP) is particularly strong in artificial intelligence, machine learning, and Kubernetes.** Kubernetes was originally developed at Google, and Google Cloud provides Google Kubernetes Engine (GKE), a mature managed Kubernetes platform. GCP also offers powerful AI and machine learning tools, including Vertex AI, making it a strong option for organizations working with modern AI and cloud-native technologies.

### Q4: Which cloud platform would you personally choose and why?

**I would personally choose Amazon Web Services (AWS)** because it provides a broad selection of services and gives users a lot of flexibility when building cloud solutions. AWS also offers widely used services such as EC2, S3, VPC, and IAM, which cover the basic requirements for computing, storage, networking, and identity management.

For a student or beginner exploring cloud computing, AWS is also a practical choice because its large ecosystem provides many learning resources and opportunities to gain experience with commonly used cloud technologies. However, the best provider ultimately depends on the organization's requirements, budget, existing technology stack, and specific workload.
